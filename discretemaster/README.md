# DiscreteMaster showcase

Статический сайт продукта: `index.html` и `functionality.html`.

Скриншоты в `assets/screens/` сняты с реального приложения на отдельной локальной демонстрационной БД. Все данные вымышлены. Рабочие данные и секреты сюда не входят.

Для локального просмотра запустите статический HTTP-сервер из корня репозитория и откройте `/discretemaster/`. Никакая сборка или установка зависимостей не нужна.

Публичный адрес: https://maxmakarov01.github.io/resume/discretemaster/

Резюме и его файлы в корне репозитория сохранены. Ветка публикации: `codex/discretemaster-showcase`.
